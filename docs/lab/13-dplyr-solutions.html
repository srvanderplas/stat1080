Filter

Using poke_types, get Pokemon matching the following criteria:

  1. Pokedex number between 800 and 900
  2. Grass type
  3. Attack stats of more than 120
poke_types |>
  filter(pokedex_no >= 800, pokedex_no <= 900) |>
  filter(type1 == "Grass") |>
  filter(attack > 120)

Mutate

Create a column named n_elevator that calculates how many of these pokemon could fit in an elevator with a weight limit of 6000 lbs. You may assume that pokemon can be infinitely compressed, so that the volume of the pokemon is not a concern.

Round your answer down to the nearest integer with the floor() function - no one needs to get hurt!

Remember, you will need to convert kg to lbs, so you may want to create an additional column named weight_lbs.

Output only gen, name, and the columns you created.

poke_types |>
  mutate(weight_lbs = weight_kg * 2.204623, 
         n_elevator = floor(6000/weight_lbs)) |>
  select(gen, name, weight_lbs, n_elevator)

Group_by + Summarize!

Work with poke_types and only worry about the primary type (type1)

Bug Pokemon by Generation

Calculate the total number of bug pokemon in each generation.

poke_types |>
  filter(type1 == "Bug") |>
  group_by(gen) |>
  summarize(Bug = n())
