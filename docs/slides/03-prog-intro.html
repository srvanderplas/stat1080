CSV Trick: Separate the Names from the Data

olive_df <- read_csv(files[8],
                     col_names = FALSE,
                     skip = 1)
olive_names <- read_csv(files[8], col_names = FALSE, n_max = 1)
olive_names <- as.character(olive_names)
olive_names <- c("row", "RegionName", olive_names[-1])
names(olive_df) <- olive_names

RStudio Projects

  • Help you keep track of the files for a data science project
  • File -> New Project -> New Directory
    • Name your new project something descriptive
    • Put the project in sensible folder
  • Move data into the project folder (into a data/ subdirectory if multiple files)
  • .R files in the project folder will find your data automatically without needing a file path.

Teaching Rocks to do Math

  • Remember you’re talking to a rock (“dumb as a box of rocks…”)
  • You have to know a concept really well before you start programming
  • Be extremely specific
  • Consider what assumptions you are making.
    • Try not to make them unless necessary.
    • If necessary, test to ensure they’re met.
