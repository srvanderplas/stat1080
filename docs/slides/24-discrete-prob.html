Monte Carlo

Steps

  1. Create a vector or tibble of things to sample from
library(tidyverse)
deck <- crossing(
  suit = c("Hearts", "Spades", "Clubs", "Diamonds"),
  tibble(
    face = c("02", "03", "04", "05", "06", "07",
             "08", "09", "10", "Jack", "Queen",
             "King", "Ace"),
    points = c(2:10, 10, 10, 10, 11)
  )
)
head(deck)
1
The crossing function creates all combinations of the things passed in to it – in this case, the suits, and the tibble with face values and points.
2
Define the four suits that exist in a deck of cards.
3
Define the face values and the points. We have to pass these in as a tibble because we don’t want all combinations of face values and points – each face value has a separate meaning. If we were going past the initial deal, we could handle Aces separately.

Steps

  1. Use sample (or slice_sample() for a tibble) to pick objects from your sampling space at random.
set.seed(19900321)
single_sample <- deck |> 
  slice_sample(n=2)
single_sample
1
When sampling, always set a seed so you get the same results every time. I use birthdays in yyyymmdd form a lot (this is from a friend).
2
slice_sample allows you to choose a proportion of the rows (with the prop argument) or the raw number (with the n argument), which is more appropriate here. You can also set different probabilities for each row with weight_by. 
# A tibble: 2 × 3
  suit     face  points
  <chr>    <chr>  <dbl>
1 Hearts   Jack      10
2 Diamonds 10        10

Steps

  1. Evaluate your draw in a way that gets you (hopefully) a single number, like an initial blackjack score.
set.seed(19900321)
deck |>
  slice_sample(n=2) |>
  summarize(points = sum(points))
1
Setting the seed means we get the same results in this chunk
2
We summarize to one row to get the initial score for blackjack, where you’re dealt two cards initially and have to decide what to do. In this case you probably? want to stay, but we can evaluate that with Monte Carlo Simulation. 
# A tibble: 1 × 1
  points
   <dbl>
1     20

Steps

  1. Repeat a LOT of times, but not infinitely many times, because I don’t have that kind of time.
library(infer) # Tidyverse library
set.seed(19900321)
results <- deck |>
  rep_slice_sample(n = 2, reps = 1000000) |>
  summarize(points = sum(points))

head(results)
1
Set the seed because we’re being good and we want results that stay the same
2
use rep_slice_sample from the infer package to slice things but also replicate them. It creates a grouped data frame based on the replicate variable that it creates.
3
Use the same summary function we used before to get the point distribution.

Steps

  1. Use your results to understand the distribution!
theme_set(theme_bw())
ggplot(results, aes(x = points)) +
  geom_histogram(
    fill = "grey", color = "black",
    binwidth = 1, center = 1
  )
1
With discrete whole-number distributions, it’s usually best to set your bin width to something sensible (1 in this case) and set bin to be centered on the whole numbers so that it’s not ambiguous what is included in each bin. Then, we know for sure that 4 and 22 (two twos and two aces) are both showing up in our sample, occasionally.
