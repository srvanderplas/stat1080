1.17 Visualizing Data Distributions

With the Cappuccino Index

Introduction

The Cappuccino Index

James Hoffmann is a YouTuber who explores coffee from many different angles. In a recent video he explored how long a barista would need to work to pay for a small cappuccino.

Coffee, as a part of our economy, as an industry, is full of these awkward questions that I do think are worth asking.

In the video, James presents the cappuccino index, which answers this at a country level.

There are some important caveats, such as tips being excluded.

Data Source & Description

Data Dictionary - cafe

variable class description
country character The country of the cafe.
city character The city of the cafe.
urban logical Whether the cafe is in an urban area.
suburban logical Whether the cafe is in a suburban area.
rural logical Whether the cafe is in a rural area.
hourly_wage_gbp double The hourly wage of a barista working in the cafe, converted to British pounds.
price_gbp double The price of a small cappuccino from the cafe, converted to British pounds.
original_currency character The original currency used by the cafe.
price double The price of a small cappuccino from the cafe, in the original currency.
hourly_wage double The hourly wage of a barista working in the cafe, in the original currency.

Data Dictionary - cappuccino_index

variable class description
country character Name of country for which cappuccino index was calculated.
index double The cappuccino index: the time in minutes a barista needs to work to afford a small cappuccino in their country.
n integer Number of cafes that were included in the calculation of the index.
minutes double The number of whole minutes in index.
seconds double The remaining number of seconds in index.
index_as_time character Index formatted as minutes and seconds, i.e., MM:SS.

Numeric Distributions

Data Wrangling

cafe_english <- cafe |>
  filter(country %in% c("Australia", "USA", "UK"))

cafe_summary <- cafe_english |>
  group_by(country) |>
  summarize(mean = mean(price_gbp), median = median(price_gbp)) |>
  pivot_longer(-country, names_to="summary") |>
  mutate(summary = factor(summary))
1
Get only the UK, US, and Australia
2
Summarize price_gbp, getting the median and mean
3
Pivot longer, so that we have long-form data with the summary name as the column name. This makes plotting easier.

ECDFs

  • Shows all of the data in the distribution
  • Continuous variables will look relatively smooth for large enough \(n\)
  • Discrete variables will have “steps”
  • Hard to see the mean, variability, range

Histograms - Cost of Cappuccino

cafe |>
  filter(country %in% c("USA", "UK", "Australia")) |>
  ggplot(aes(x = price_gbp, fill = country)) + 
  geom_histogram(binwidth = .2) + 
  guides(fill = "none") + 
  facet_grid(country~., scales = "free_y")
1
Setting scales = "free_y" allows the y-axis scale to vary between the different countries, de-emphasizing the lower amount of data in Australia relative to the other two countries.

Density Plots

ggplot(cafe_english, 
       aes(x = price_gbp, 
           color = country)) + 
  geom_density(adjust = .5)
  • Smoothed out version of a histogram
  • Masks rounded/discrete variables
  • With smaller bandwidth/adjustment, discrete variables look like zigzags.
  • Adjust bandwidth using geom_density(adjust=XXX)
    • Try values of XXX of 0.5, 1.5 to start

Box Plots

ggplot(cafe_english, 
       aes(x = country, 
           y = price_gbp)) + 
  geom_boxplot()
  • Box:
    • lower: 25th percentile
    • upper: 75th percentile
    • middle: median, 50th percentile
  • Whiskers:
    • smallest observation that is greater than or equal to (lower hinge - 1.5 * (upper - lower))
    • largest observation that is less than or equal to (upper hinge + 1.5 * (upper - lower))
  • Outliers: anything not covered by the whiskers are shown as individual points

Violin Plots

ggplot(
  cafe_english, 
  aes(x = country, 
      y = price_gbp, 
      fill = country)) + 
  geom_violin(adjust = 0.75) + 
  geom_boxplot(
    width=.1, 
    fill = "white",
    outliers = FALSE) + 
  guides(fill = "none")
  • Density curve plotted vertically, then mirrored
  • Often shown with a boxplot (or quantile lines) overlaid on top
