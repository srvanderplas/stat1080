Why R?

There are only two kinds of languages: the ones people complain about and the ones nobody uses.

– Bjarne Stroustrup (creator of the C++ programming language)

What is R?

  • An open-source clone of S, which was a programming language developed at the Bell Telephone Laboratories in 1976.
  • A language built for working with data
  • With all the features of a general purpose language
  • plus functional programming
  • and at least 5 object-oriented systems

Pros and Cons

Pros:

  • Excellent packages for data graphics
  • Interactive and responsive
  • Tons of tutorials and materials
    • Big book of R - TONS of free online textbooks
    • Tidy Tuesday videos - how to clean, analyze, and visualize data in R
  • Supportive community - R ladies+, , #rstats, #statistics

Cons

  • Optimizes programmer time - computing time can be slower
    • Industry uses R for prototyping, Python/C for production
  • Easy to write bad/hard-to-maintain code
    This is true in almost every language
  • Different conventions than C/Python/Java
    Counting from 1, 2, 3, … rather than 0, 1, 2, …

Why Not Spreadsheets?

  1. Reproducibility. Code is like a recipe, Spreadsheets are one-off analyses. Things get changed accidentally.
  2. Spreadsheet references are less readable than variable names
  3. It’s best to separate data, code, and output. Spreadsheets mix them.
  4. Spreadsheet functionality is limited compared to add-on libraries
  5. Excel charts are terrible (personal opinion)

RStudio Projects

  • Help you keep track of the files for a data science project
  • File -> New Project -> New Directory
    • Name your new project something descriptive
    • Put the project in sensible folder
  • Move data into the project folder (into a data/ subdirectory if multiple files)
  • .R files in the project folder will find your data automatically without needing a file path.
