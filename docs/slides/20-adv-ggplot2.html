Facets

facet_xxx(~variable_name, scales = ..., space = ...)

  • xxx: wrap or grid.
    • grid allows var1 ~ var2, rows ~ cols
    • wrap allows ~var1
    • With both, you can (but probably shouldn’t) use var1 + var2 to get a combination
  • scales = fixed, free_x,free_y, orfree` (e.g. x and y)
    • free options work best with facet_wrap
    • free scales allow the range of the subplot to reflect only the data in that facet
    • comparisons get visually harder to make, but it saves space
  • space = free_x, free_y, fixed – only one column can be free space
    • This changes the amount of space allocated to each facet (and also changes the range)

Wrap facets around. Set facets to have unconstrained y-scales, which adjusts the range of x for the subplots to fit each individual range of data.

Facets – free_y for space and scales

p + 
  facet_wrap(
    ~species,
    scales = "free_y",
    space = "free_y")
1
Facet by species, and allow facets to wrap around into multiple rows. Allowing scales and space on the y-axis to vary forces ggplot2 to lay the facets out in rows, rather than columns.

Cognitive Limits

Short Term Memory

  • Are there colors associated with your variables?

    • cold / hot, / ,        amount of plant cover       ,        snow depth       

    Using common color associations reduces cognitive load

  • Minimize categories: Keep # legend entries \(\leq 7\)

    \(7 \pm 2\) is thought to be the limit of short-term memory.

Graphical Conventions

  • X-axis: left is smaller, right is larger
  • Y-axis: bottom is smaller, top is larger
  • Color: less saturated (pastel/white) is smaller, more saturated (bold color) is larger


- Use the smallest dimension possible - don’t use area when length will do - fake 3D perspective is misleading - Pixel accuracy - the number of pixels should match the magnitude of the data! - Infographics, logos, etc. look cute (sometimes?) but are often less accurately perceived.
